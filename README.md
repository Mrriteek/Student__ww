# STUDENT HELP (plain HTML/CSS/JS)
No build, no server. Upload the whole folder to Netlify (drag & drop), Vercel, GitHub Pages or any hosting. You get a link to share.
- Open `/#/admin` (or the small "Admin" link in the footer) to log in. Change UPI ID, Telegram link and prices.
- Changes made in the admin panel save only in YOUR browser. Click "Export settings.js" and replace `settings.js` on your hosting so everyone sees them.
- Admin login needs HTTPS (all hosts above give it).
- The PDF is NOT on the website. After the student messages you on Telegram, check the payment in your bank app, then send the PDF link personally.
